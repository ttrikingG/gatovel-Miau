O Miau é um framework frontend pequeno, modular e simples para a Web, desenvolvido como parte do ecossistema Gatovel.

Projetado com foco em modularidade, simplicidade e uso das APIs nativas da Web, o Miau fornece uma base leve para a construção de aplicações frontend modernas.
