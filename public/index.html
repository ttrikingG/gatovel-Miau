MIAU

Um framework frontend pequeno, modular e simples para a Web.

miau — documentação

1 Instalação — MIAU

Instale o Miau através do npm. 

# instalar o Miau
$ npm install miau

2 Início rápido — MIAU

  • 1
    Crie seu projeto

    Crie uma nova aplicação utilizando o Miau.

  • 2
    Instale o framework

    Adicione o Miau ao projeto através do npm.

  • 3
    Comece a desenvolver

    Utilize os módulos do Miau para construir sua aplicação. 

// importar recursos do Miau
import {
    createElement,
    Router,
    State
} from 'miau';

3 Referência da API — MIAU

Principais módulos disponíveis no núcleo do Miau.

createElement (tagName, options)

Cria elementos HTML utilizando a API DOM nativa.

Router (routes, options)

Gerencia a navegação da aplicação no navegador.

State (initialValue)

Cria um estado reativo simples para a aplicação.

Http (baseUrl)

Realiza requisições HTTP utilizando a Fetch API.

interpolate (template, data)

Resolve interpolação simples utilizando a sintaxe ^^....
